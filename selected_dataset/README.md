# Dataset Seleccionado: Gestantes Perú

## Descripción del conjunto de datos

El presente conjunto de datos contiene información demográfica, geográfica y asistencial correspondiente a gestantes atendidas en establecimientos de salud de Perú. Entre las variables disponibles se incluyen edad, ubicación territorial, nivel del establecimiento de salud, características de la atención recibida y algunos antecedentes antropométricos de las pacientes.

## Criterios para la selección del dataset

La elección de este conjunto de datos se realizó a partir del análisis exploratorio efectuado sobre cuatro datasets pertenecientes a distintos dominios temáticos. La selección consideró aspectos relacionados con la calidad aparente de los datos, la diversidad de variables disponibles y el potencial analítico del conjunto.

## Fortalezas identificadas durante el análisis exploratorio

Durante el EDA se observó que el dataset presenta características propias de datos provenientes de contextos reales, incluyendo la existencia de valores faltantes y posibles valores extremos, elementos que enriquecen el proceso de preparación y análisis de la información.

Asimismo, el conjunto incorpora variables de distinta naturaleza, incluyendo antecedentes demográficos, territoriales y asistenciales, permitiendo explorar relaciones potencialmente relevantes entre las características de las gestantes y los servicios de salud asociados a su atención.

Otra fortaleza identificada corresponde al tamaño del conjunto de datos, el cual proporciona un volumen suficiente de observaciones para desarrollar análisis más robustos y evaluar distintas estrategias metodológicas.

## Limitaciones identificadas

A pesar de sus fortalezas, el dataset presenta algunas limitaciones que deben ser consideradas. En particular, ciertas variables requieren una comprensión más profunda respecto de su significado operativo y utilidad analítica antes de ser incorporadas en etapas posteriores del análisis. Asimismo, la presencia de datos faltantes hace necesario implementar procedimientos adecuados de preprocesamiento.

## Justificación de la selección

En comparación con los otros conjuntos de datos analizados, Gestantes Perú fue considerado el más adecuado debido a que presentó una estructura de datos más consistente con situaciones reales, una mayor heterogeneidad en sus variables y desafíos analíticos que reflejan de mejor manera las dificultades habitualmente encontradas en proyectos de ciencia de datos.
